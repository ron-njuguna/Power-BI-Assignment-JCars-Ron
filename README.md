# Power-BI-Assignment-JCars-Ron

## Project Overview
This project analyzes JCars sales data using Power BI.

## Tools Used
- Power BI
- PostgreSQL
- Power Query
- DAX

## Dashboard Features
- Executive KPIs
- Revenue Trend
- Revenue by Region
- Revenue by Car Make
- Revenue by Branch
- Revenue by Vehicle Type
- Payment Analysis
- Customer Analysis
- Sales Representative Performance
- Interactive Slicers

## Key Insights
- Toyota generated the highest revenue.
- SUVs were the best-performing vehicle type.
- Corporate customers contributed significant revenue.
- Revenue differed across branches.
- Payment methods varied across customers.


Recommendation 1

Increase inventory and marketing for the highest-performing vehicle brands and types to maximize sales.

Recommendation 2

Investigate low-performing branches and provide additional sales support and training.

Recommendation 3

Improve payment processing and customer engagement to encourage timely payments and improve customer satisfaction.
